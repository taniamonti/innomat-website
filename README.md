# Innomat - Automation AG Website

A modern, responsive website showcasing **Innomat - Automation AG** and its complementary companies:

## Companies Featured

### **Innomat - Automation AG**
Software and innovation development, industrial automation, system architecture, and project management. Specializes in digitalization and system integration for manufacturing.

### **Staveb Automation AG**
Robotics and automation solutions including:
- Autonomous Mobile Robots (AMR)
- Bin Picking and Machine Tending
- Complete automation systems and retrofit solutions
- Vision systems and AMR fleet management

### **Kalisto**
An industrial IoT and digitalization platform featuring:
- Real-time data connectivity and visualization
- SCADA and HMI solutions
- Smart Factory integration
- End-to-end system toolkit from sensors to ERP

## Purpose

This website serves as a comprehensive digital presence for three interconnected Swiss engineering companies, demonstrating their combined expertise in industrial automation, robotics, digitalization, and IoT solutions. It provides information about services, products, case studies, team members, and integrated booking functionality for consultations.

## Key Sections

- **Hero/Home**: Overview of services and key metrics
- **Competencies**: Detailed breakdown of each company's expertise
- **Products & Services**: Features of each division
- **Team**: Team members across all three companies
- **Case Studies**: Real customer implementations
- **News**: Latest updates and insights
- **Booking**: Online appointment scheduling system

## Technology

Built with semantic HTML5, modern CSS3 (including CSS Grid, Flexbox), and vanilla JavaScript for interactive components like filtering, booking, and team member cards.
